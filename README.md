# CUBE STRIKE 2（キューブストライク２）

ブロックになって転がって撃ち合う、チーム対戦FPS「キューブストライク」の続編です。

## あそびかた
1. 「Code」→「Download ZIP」でダウンロードして、ZIPを ひらく
2. `index.html` をブラウザ（Chrome / Edge / Safari）で ひらく
   - CS1 と同じ場所に置かないでね（べつの フォルダに 入れる）
   - 古い画面のままなら **Ctrl + Shift + R** で読みこみなおす

## CS2 で ふえたもの
- **銃を 2つ** もてる（おなじ銃を 2つでも OK）。スナイパー系を もつと 銃は 1つだけ
- **銃は 57しゅるい**（CS1 の 21しゅるい ＋ 新しい 36しゅるい）
  - ふつうの銃・スナイパー系・ふしぎな武器（ブラックホール・いなずま・ブーメラン…）・回復サポート
- **全部の銃の 弾が とんでいく**（レーザーと かえんほうしゃき 以外）
- **部品 35しゅるい**（武器こうぼう）
  - ふつうの部品 20しゅるいは いくつでも かさねられる
  - とくしゅ部品 15しゅるいは 1こまで。つよいけど なにかが よわくなる（例: 壁貫通 → 体力はんぶん）
  - 1つの銃に 30こまで。1こ つけるごとに リロードが +30%
  - 部品は 銃の 3Dモデルにも 見える
- **組み合わせ（銃2つ＋部品＋ボム）を 10こまで ほぞん**
- **お絵かきアトリエ**: からだの 6面に 16×16 の ドットで 絵が かける
- **ボスレイド**: 5たいの ボスを みんなで たおす（1〜4人＋コンピューターの なかま）
- みんなの 体力は 200

CS1 とは セーブデータ・オンラインが べつです。
